# Исправление запуска PostgreSQL

Исправлена ошибка:

> изменить имя столбца "ID заявки" на "Номер заявки" в представлении нельзя

Причина:
PostgreSQL не разрешает переименовывать колонки существующего VIEW через `CREATE OR REPLACE VIEW`.

Что сделано:
- перед пересозданием читаемых представлений CRM сервер теперь удаляет старые VIEW через `DROP VIEW IF EXISTS ... CASCADE`;
- таблицы и заявки не удаляются;
- данные лидов сохраняются;
- после запуска представления создаются заново уже с актуальными колонками, включая номер заявки.

После распаковки:
1. Скопируйте свой `.env` в корень проекта.
2. Запустите `npm start`.
