# Связка номера заявки с CRM

Что сделано:

- Номер плана визита, который видит клиент на сайте, теперь отправляется в CRM как `leadNumber`.
- В CRM номер отображается в карточке заявки как крупный бейдж `№....`.
- Номер также отображается в метаданных заявки, в таблице последних заявок и в CSV-выгрузке.
- Для обычной формы сайт/сервер генерирует отдельный номер заявки автоматически.
- Для PostgreSQL добавлена колонка `lead_number`; при запуске проекта она создаётся автоматически через `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`.
- Старые заявки не ломаются: если `leadNumber` ещё нет, CRM пытается взять номер из текста «План визита №...», а если номера нет — показывает короткий хвост технического ID.

Логика:
- Один проход интерактивного маршрута = один номер.
- При переключении вариантов номер не меняется.
- После успешной отправки следующая новая заявка получает новый номер.
