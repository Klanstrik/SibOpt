# MCP для проекта «Сибирь-Оптика»

В проект добавлен отдельный **read-only MCP-сервер** для разработки и демонстрации работодателю. Он не меняет публичный сайт и не встраивается в клиентскую часть. MCP запускается отдельно и даёт AI-инструменту доступ к данным проекта через безопасные tools.

## Что умеет MCP

Сервер читает:

- CRM-заявки;
- товары каталога;
- публичные настройки бизнеса;
- SEO-страницы в `public/*.html`;
- базовую статистику по заявкам и закрытым сделкам.

Если в `.env` указан `DATABASE_URL`, MCP читает реальные данные из PostgreSQL. Если PostgreSQL недоступен, MCP автоматически переходит на JSON-файлы из папки `data/`.

## Безопасность

MCP работает в режиме **read-only**. Он не создаёт, не изменяет и не удаляет заявки, товары, настройки или файлы сайта.

По умолчанию персональные данные клиентов маскируются:

- имя показывается частично;
- телефон показывается частично;
- сообщения и заметки скрываются.

Полные данные можно включить только локально через:

```env
MCP_EXPOSE_PERSONAL_DATA=true
```

Для демонстрации работодателю лучше оставить:

```env
MCP_EXPOSE_PERSONAL_DATA=false
```

## Установка

```powershell
npm install
```

## Проверка сайта

```powershell
npm start
```

Сайт откроется на:

```text
http://localhost:3000
```

## Проверка MCP

MCP обычно запускается не вручную, а AI-клиентом через stdio. Но для быстрой проверки можно выполнить:

```powershell
npm run mcp
```

Если зависимостей хватает, процесс запустится и будет ждать подключения MCP-клиента. Остановить можно через `Ctrl + C`.

## Пример подключения к AI-клиенту

В MCP-клиенте нужно указать команду запуска:

```json
{
  "mcpServers": {
    "sibir-optika": {
      "command": "node",
      "args": ["C:/путь/к/проекту/mcp-server.mjs"],
      "env": {
        "MCP_EXPOSE_PERSONAL_DATA": "false"
      }
    }
  }
}
```

Путь нужно заменить на реальный путь к папке проекта на вашем компьютере.

## Доступные tools

- `get_mcp_status` — проверить подключение к PostgreSQL/JSON и режим безопасности;
- `get_project_summary` — краткое описание проекта и готовая формулировка для резюме;
- `get_crm_summary` — сводка по CRM без персональных данных;
- `list_leads` — список заявок с фильтрами и маскировкой данных;
- `search_products` — поиск по каталогу товаров;
- `get_business_settings` — публичные настройки бизнеса;
- `get_sales_report` — отчёт по заявкам, статусам и закрытым сделкам;
- `audit_data_quality` — проверка пустых контактов, товаров без фото/описаний и тестовых заявок;
- `search_seo_pages` — поиск SEO-страниц;
- `audit_seo_pages` — технический SEO-аудит HTML-страниц.

## Как это описать в резюме

> Добавил к проекту «Сибирь-Оптика» read-only MCP-сервер на Node.js для интеграции с AI-инструментами разработки. MCP читает CRM-заявки, каталог товаров, настройки и SEO-страницы из PostgreSQL через `DATABASE_URL` с fallback на JSON-файлы, маскирует персональные данные и предоставляет tools для аудита CRM, каталога и SEO.

## Как это объяснить на собеседовании

> MCP не меняет сам сайт для посетителей. Это отдельный dev-инструмент, который позволяет AI-ассистенту работать не на догадках, а с реальными данными проекта: заявками, товарами, настройками и SEO-страницами. Я сделал его read-only, чтобы исключить случайное изменение данных, и добавил маскировку персональных данных по умолчанию.
