# Убрано автозаполнение комментария

Исправлено:

- После подбора визита поле «Комментарий» в обычной заявке больше не заполняется автоматически.
- Комментарий остаётся пустым, пока клиент сам ничего не напишет.
- Кнопка теперь называется «Перейти к обычной форме».
- При переходе из подбора в обычную форму могут переноситься базовые данные вроде имени, телефона, услуги и рецепта, но не длинный текст подбора.
- Отдельная отправка подбора визита всё ещё сохраняет короткую информацию в CRM, потому что это отдельная заявка по подбору.

Остальное не откатывалось:
- рекомендации только при выборе «Посоветуйте салон»;
- отзывы;
- быстрая заявка;
- CRM;
- номера заявок;
- раздел «Номера заявок»;
- читаемые карточки CRM;
- MCP;
- SEO.
