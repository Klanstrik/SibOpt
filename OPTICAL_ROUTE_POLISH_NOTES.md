# Правки интерактивного маршрута

Исправлено:

- Номер плана визита больше не меняется при переключении салона. Он создаётся один раз для текущего прохождения маршрута.
- Кнопка «Помогите выбрать» переименована в «Подберите салон за меня» и теперь реально подбирает салон по ответам:
  - срочно / сегодня / быстрее — Дуси Ковальчук;
  - не срочно — Учительская 33;
  - если есть сомнения — сайт объясняет, почему предложен конкретный салон.
- В результате добавлен блок «Как мы выбираем салон», если пользователь просит подобрать салон автоматически.
- После отправки заявки через новый маршрут появляется всплывающее окно с подтверждением.
- После отправки обычной формы заявки тоже появляется всплывающее окно с подтверждением.
- Обычная форма записи сохранена и работает отдельно от новой функции.

Все предыдущие правки сохранены: Arial/Helvetica, тексты по салонам, корректные формулировки без «установки линз», SEO, CRM, PostgreSQL и MCP.
