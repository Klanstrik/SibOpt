# Сибирь Оптика — каталог с поиском

## Что добавлено

- Отдельная секция “Очки”
- Отдельная секция “Линзы”
- Отдельная секция “Услуги мастера”
- Общий поиск по каталогу
- Фильтр по разделу
- Фильтр по бренду
- Фильтр по типу
- Карточки товаров с брендом, типом, формой, ценой, наличием и тегами
- Кнопка “Уточнить”, которая подставляет выбранный товар в форму заявки

## Как запустить

1. Открой папку в VS Code.
2. Открой `index.html`.
3. Правой кнопкой мыши → Open with Live Server.

## Где менять товары

Открой `config.js` и редактируй массив `products`.

## Как добавить фото товара

1. Создай папку `images`.
2. Положи туда фото, например `frame-1.jpg`.
3. В товаре укажи:

image: 'images/frame-1.jpg'

Если фото нет, карточка покажет стильную заглушку.

## Важные поля товара

section:
- frames
- lenses
- services

category:
- Очки
- Линзы
- Контактные линзы
- Услуги мастера

brand:
- название бренда или “Мастерская”

type:
- Женские
- Мужские
- Детские
- Универсальные
- Линзы для очков
- Покрытие
- Контактные
- Замена линз
- Изготовление
- Подгонка
