# Нормальная SEO-версия без видимых SEO-блоков

## Что исправлено

Удалены страницы-карты и видимые SEO-разделы:
- brendy-optiki.html
- poisk-po-tegam.html
- populyarnye-zaprosy.html
- vse-zaprosy-*.html

С главной страницы убраны блоки:
- “Поиск по брендам”
- “Все SEO-теги”
- “Популярные формулировки поиска”
- “Расширенная карта запросов”

## Как теперь работает SEO

Остались отдельные посадочные страницы под запросы и бренды, но они выглядят как нормальные страницы для пользователя:
- заголовок
- понятное описание
- преимущества
- форма заявки
- контакты
- ссылки на основные разделы

## Важно

SEO-запросы не должны быть видимой простынёй на сайте. Они должны быть распределены по нормальным страницам, title, description, sitemap и текстам.

Перед публикацией:
- заменить https://sibir-optika.ru в sitemap.xml и robots.txt
- заполнить config.js реальными контактами
- оставить только бренды, которые реально будут продаваться или заказываться
