# Исправленная SEO-версия

## Что исправлено

С главной страницы убраны видимые SEO-блоки:
- “Популярные формулировки поиска”
- “Расширенная карта запросов”
- большие карточки SEO-запросов

Теперь посетитель видит нормальный сайт оптики, а SEO-страницы остаются отдельными посадочными страницами.

## Что осталось

Остались отдельные SEO-страницы под:
- купить очки
- очки купить
- купить линзы
- линзы купить
- оправы
- контактные линзы
- бренды
- Сибирь Оптика
- оптика рядом
- услуги мастера

## Что сделано с картами тегов

Страницы-карты тегов получили noindex:
- poisk-po-tegam.html
- populyarnye-zaprosy.html
- brendy-optiki.html

Они не должны индексироваться как обычные страницы, чтобы сайт не выглядел как SEO-спам.
