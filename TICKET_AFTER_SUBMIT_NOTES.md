# Номер заявки после оформления

Исправлена логика номера заявки:

- На этапе выбора «Оптического маршрута» номер больше не показывается.
- При переключении салонов номер не меняется, потому что номер ещё не выдан.
- Номер создаётся только после отправки формы, когда backend реально сохраняет заявку в CRM/PostgreSQL.
- После успешной отправки клиент видит всплывающее окно: «Вы оформили заявку №....».
- Этот же номер сохраняется в CRM как `leadNumber` и отображается в карточке заявки, таблице последних заявок и CSV-выгрузке.
- Обычная форма тоже получает номер только после успешного оформления заявки.
