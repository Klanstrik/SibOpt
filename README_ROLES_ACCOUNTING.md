# Роли CRM и выгрузки для бухгалтерии

В CRM оставлены две роли:

## 1. Администратор

Полный доступ:

- главная панель;
- заявки;
- изменение статусов и заметок;
- удаление заявок;
- каталог товаров;
- настройки сайта;
- бухгалтерские отчёты;
- экспорт в XLS и CSV.

## 2. Сотрудник

Общая роль для менеджеров и бухгалтерии.

Доступ:

- главная панель;
- просмотр заявок;
- изменение статусов и заметок;
- раздел «Бухгалтерия»;
- экспорт отчётов в XLS и CSV.

Ограничения:

- нельзя удалять заявки;
- нельзя редактировать каталог;
- нельзя менять настройки сайта.

## Переменные окружения

Добавьте в `.env`:

```env
ADMIN_PASSWORD=admin12345
STAFF_PASSWORD=staff12345
```

## Запуск

```bash
npm install
npm start
```

После запуска CRM доступна по адресу:

```text
http://localhost:3000/crm/
```
