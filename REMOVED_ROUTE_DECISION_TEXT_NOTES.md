# Убран лишний текст в результате подбора

Удалены фразы в карточке результата:

- «Вы выбрали Дуси Ковальчук — это логичный вариант...»
- «Вы выбрали Дуси Ковальчук — быстрый салон...»
- блок «Как сайт советует салон...»

Теперь в результате подбора остаётся только полезная информация:
- что нужно;
- рецепт;
- срок;
- выбранный/рекомендованный салон;
- предупреждение по сроку, если оно реально нужно;
- что будет после заявки;
- план визита.

CRM, номера заявок, отзывы, быстрая заявка, MCP и SEO не откатывались.
