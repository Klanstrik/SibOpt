# SEO-релиз Сибирь-Оптика

В этом архиве внесены изменения для SEO и формы заявок.

## Что изменено

1. Убрана обязательная галочка согласия из формы заявки.
2. Вместо галочки добавлен корректный текст под формой: пользователь соглашается с политикой обработки персональных данных при нажатии кнопки отправки.
3. Добавлены FAQ-блоки на главную и SEO-посадочные страницы.
4. Добавлена микроразметка FAQPage для страниц с FAQ.
5. Добавлена микроразметка Service для коммерческих страниц.
6. Добавлена микроразметка WebPage.
7. Усилена микроразметка Optician/LocalBusiness: телефон, адреса салонов, часы работы, услуги.
8. Добавлены local SEO метатеги geo.region и geo.placename.
9. Добавлены og:image:alt и twitter:image.
10. Обновлён sitemap.xml: добавлен корневой URL, lastmod и приоритеты.
11. Обновлён robots.txt: добавлен Host для Яндекса и sitemap.
12. Исправлена поддержка старых ID ссылок на карты на SEO-страницах: yandexMapLink, gisLink, routeLink, mobileRoute.
13. Добавлена динамическая Product/ItemList schema для активных товаров витрины.

## Важно

Файл .env специально не добавлен в архив. Скопируйте свой локальный .env в корень проекта после распаковки, если он нужен для запуска на вашем компьютере или сервере.
