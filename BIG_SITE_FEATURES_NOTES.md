# Функции как на крупных сервисных сайтах

Добавлено после анализа подхода больших сайтов:

1. Центр выбора
- На главной появился блок «Начните с задачи, а не с формы».
- Пользователь выбирает сценарий:
  - подобрать визит;
  - открыть сложные линзы;
  - открыть оправы;
  - открыть ремонт;
  - проверить статус заявки.

2. Проверка статуса заявки
- Добавлен публичный блок «Проверьте заявку по номеру».
- Клиент вводит:
  - номер заявки;
  - последние 4 цифры телефона.
- Сайт показывает безопасный статус без личного кабинета.
- Данные клиента полностью не раскрываются: не показываются имя, полный телефон, внутренние заметки и комментарии CRM.

3. API
- Добавлен публичный endpoint:
  GET /api/lead-status?number=4821&phoneLast4=2981
- Endpoint ищет заявку по `leadNumber` и сверяет последние 4 цифры телефона.

4. Связка с CRM
- Статус берётся из CRM.
- Если сотрудник меняет статус заявки в CRM, клиент при проверке видит актуальный человекопонятный статус.

5. После отправки заявки
- В окне успешной отправки теперь написано сохранить номер заявки.
- По этому номеру можно проверить статус на сайте.

Сохранено:
- экспертный раздел линз, оправ и ремонта;
- страницы /lenses.html, /frames.html, /repair.html;
- отзывы;
- подбор визита;
- быстрая заявка;
- CRM;
- раздел «Номера заявок»;
- читаемые карточки CRM;
- MCP;
- SEO.
