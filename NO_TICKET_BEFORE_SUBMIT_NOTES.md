# Номер заявки только после оформления

Исправлено:

- В блоке «персональный маршрут» больше нет номера до отправки заявки.
- При переключении салонов, сроков и вариантов ничего не меняет номер, потому что номер ещё не создан.
- На этапе выбора показывается только: «Ваш предварительный план визита».
- После нажатия «Записаться по этому плану» сервер создаёт заявку и присваивает номер.
- После успешного оформления клиент видит всплывающее окно: «Вы оформили заявку №....».
- Этот же номер сохраняется и отображается в CRM.
- Добавлен cache-bust для `script.js` и `styles.css`, чтобы браузер не показывал старую версию из кэша.

Важно: после замены архива перезапустите сервер и сделайте Ctrl+F5 в браузере.
