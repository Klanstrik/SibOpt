# Формулировки для резюме и собеседования

## Коротко для резюме

Добавил read-only MCP-сервер на Node.js для интеграции проекта с AI-инструментами разработки: сервер читает CRM-заявки, каталог товаров, настройки и SEO-страницы из PostgreSQL через `DATABASE_URL` с fallback на JSON-файлы, маскирует персональные данные и предоставляет tools для аудита CRM, каталога и SEO.

## В блок «Проекты»

**Сибирь-Оптика** — сайт и CRM для салона оптики на Node.js с PostgreSQL/JSON-хранилищем, управлением заявками, закрытыми сделками, каталогом товаров, SEO-страницами и отдельным read-only MCP-сервером для AI-assisted разработки. MCP-интеграция позволяет AI-инструментам безопасно анализировать заявки, товары, настройки и SEO-страницы проекта без изменения боевых данных.

## Как сказать на собеседовании

Я добавил MCP не в публичную часть сайта, а как отдельный инструмент разработки. Он запускается отдельно от `server.js`, подключается к PostgreSQL через `DATABASE_URL`, умеет fallback на JSON-файлы и предоставляет AI-клиенту tools для анализа CRM, каталога и SEO. Все действия read-only, а персональные данные клиентов по умолчанию маскируются.
