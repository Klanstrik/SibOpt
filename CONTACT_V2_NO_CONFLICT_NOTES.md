# Контакты переписаны без конфликтов CSS

Контактный блок заменён на новую версию с уникальными классами `so-contact-v2`, чтобы старые правила `.contact-main`, `.contact-card`, `.contact-grid` больше не могли ломать внешний вид.

Также добавлен critical CSS прямо в `index.html`, чтобы блок точно отображался нормально даже при конфликте или кэше внешнего CSS.
